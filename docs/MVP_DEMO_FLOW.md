# 발표 시연 시나리오

## 오프닝

수원 영통구에 카페를 열려고 했던 예비창업자가 있었습니다. 유동인구도 많고, 주변 카페도 잘 되는 것처럼 보였습니다. 그런데 그 지역에서 같은 업종이 반복적으로 폐업해왔다는 사실은 알지 못했습니다. 창업나침반 경기는 바로 이런 위험을 창업 전에 보여주는 서비스입니다.

## 데모 흐름

1. 업종 `카페` 선택
2. 지역 `수원시 영통구` 선택
3. 분석 시작
4. 대시보드에서 종합 점수 64점, 반복 폐업 지수 78점 확인
5. 반복 폐업 레드존 화면에서 위험 Heatmap 확인
6. AI 상권 생존 리포트 확인
7. “프랜차이즈로 들어가면 위험이 줄어들까?” 질문
8. 후보 입지 비교 화면에서 수원 권선구가 대체 후보로 더 안정적인지 확인

## 심사 질문 방어

### 기존 상권 서비스와 뭐가 다른가?
기존 서비스는 현재 상권 통계를 보여준다. 창업나침반은 인허가·폐업 데이터를 이용해 같은 업종이 반복적으로 실패한 지역을 보여준다.

### 공공데이터가 실시간이 아닌데 괜찮은가?
실시간 매출 예측이 아니라 창업 전 위험 진단이다. 반복 폐업 패턴은 과거 시계열 데이터가 핵심이기 때문에 공공데이터의 특성과 잘 맞는다.

### AI는 뭘 하는가?
점수 모델 결과 JSON을 기반으로 리포트를 생성하고, 사용자의 추가 질문에 같은 데이터 근거로 답변한다.
